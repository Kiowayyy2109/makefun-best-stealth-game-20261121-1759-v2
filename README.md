# Nightshade — The Gilded Vault

[![make.fun](https://make.fun/badge/competition/best-stealth-game-20261121-1759)](https://make.fun/competitions/best-stealth-game-20261121-1759)

A top-down 2D stealth game built for the make.fun competition
**"Make the best stealth game"** (`best-stealth-game-20261121-1759`).

You are Nightshade, a thief slipping through a gilded night museum to steal
three relics from each of four vaults — and reach the exit unseen.

## How to play

- **WASD / Arrow keys** — move
- **Shift** — sneak (slow, quiet, harder to spot)
- **Q** — toss a coin to distract the nearest guard
- **E** — pick up a relic / interact
- **R** — restart the level, **M** — mute, **P** — pause

Guards patrol with vision cones. Stay out of the cones, hide in shadow pools,
and watch the suspicion meter: `?` means a guard is getting wary, `!` means
you have been spotted. A spotted guard raises the alarm and the others
converge on you. Cameras sweep their own cones, and the inner vault is
criss-crossed with laser tripwires. Collect all three relics to unlock the
exit, then slip out.

## Running it

Open `game/index.html` in a desktop browser (or serve `game/` with any
static server). No network, no build step — everything is plain static files.
